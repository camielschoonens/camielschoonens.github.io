Over the past few days I worked with Claude to build a travel blog from scratch for our upcoming family trip to Costa Rica this summer. The result is [puravidareis.nl](puravidareis.nl), a Jekyll-based blog running the Chirpy theme (like I'm doing here too), hosted on Cloudflare Pages with automatic deployments triggered by Git pushes.

The stack ended up being surprisingly capable for a static site: Cloudflare R2 for image hosting, Matomo for privacy-friendly analytics, and an RSS-to-Mastodon pipeline for automatic toots on new posts. The entire workflow is write a post locally or on iPad via Working Copy, push to GitHub, and Cloudflare builds and deploys in under 60 seconds. If you are thinking about spinning up a personal site or travel blog, Jekyll with Cloudflare Pages is a solid, low-maintenance setup worth considering.
